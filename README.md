ExploreAgent. -  LLM-Powered Autonomous Exploratory Testing Agent

 Why I'm Building ExploreAgent

Throughout my career in software testing, I've noticed something interesting.

Some of the most important bugs I've reported were discovered during manual or exploratory testing, not while executing existing regression test cases.

And I've seen this happen across different projects.

Automation testing plays an important role. It helps us verify that existing functionality is working and that new changes haven't broken something that was already working.

But there's another side of testing that I find equally important.

What about the issues we haven't anticipated? What about unusual user behavior, unexpected combinations of actions, or scenarios nobody thought to automate?

That's where exploratory testing has helped me discover some of the most valuable bugs.

And that got me thinking.

**What if I could build an AI agent that explores an application like a tester, rather than simply executing predefined test cases?**

An agent that can understand a webpage, interact with it, decide what to investigate next, and identify potential issues.

That's the idea behind ExploreAgent.

I'm not trying to replace regression automation or manual testers. I want to explore whether LLMs can help us discover issues that traditional scripted automation might miss.

I'm building this from scratch using TypeScript, Playwright, and Gemini, learning and experimenting along the way.

It's still in the early stages, but the problem I'm trying to solve is something I've experienced firsthand.
